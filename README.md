# 🚀 API - [Buffet Infantil FestaFácil]

## 📌 Sobre o Projeto
O projeto pretende criar um site do Buffet, com rotas de sobre a loja e pacotes.

## 🛠️ Tecnologias Utilizadas
- Node.js
- Express.js
- Thunder Client (para testes)

## 📡 Endpoints da API (Rotas)
| Método | Rota | Descrição |
| :--- | :--- | :--- |
| `GET` | `/` | Boas-vindas a API |
| `GET` | `/sobre` | Informações sobre a loja |
| `GET` | `/pacotes` | Lista as festas: pacote, convidados e valor  |


## 🧪 Como Rodar e Testar
1. Clone o repositório
2. Execute `npm install`
3. Inicie com `node server.js`
4. Teste as rotas no Thunder Client
